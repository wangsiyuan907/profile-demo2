公司 IP 视觉探索与三维延展

INTERNAL IP  / 2024

公司内部 IP 征集中的两项工作：我独立完成了“铠甲勇士”概念提案；在最终入选的另一方向中，我依据团队已确定的二维设定，完成六位角色的三维化与五视图制作。

任务
公司内部 IP 征集，用于后续海报、PPT 与周边物料
方向1
独立提案概念、角色建模与长图呈现；挺进TOP5
方向2
入选方案延展：既定二维角色的三维五视图制作

从角色设定，延伸到一套完整的 IP 提案。

“铠甲勇士”是我在内部征集中独立提出的方向。我完成了角色创意、三维建模及提案长图，将角色性格、造型视图和应用设想整理为一套可供评审的方案。该方向最终未被选用。

将二维设定，转化为稳定的三维角色视图。

入选方向的角色概念与二维设定由团队其他成员完成。我的职责是将六位角色转化为三维形象，输出合影及每位角色的五视图，作为后续 AI 训练与生成时的造型参考，帮助保持角色在不同视角下的一致性。
